# Gideon – wersja demo w przeglądarce

Gideon 4.302 (sterowanie napędami scenicznymi) uruchamiany w przeglądarce, bez pulpitu i bez sterownika PLC.

- wszystkie napędy są symulowane – w przeglądarce działa ta sama logika co w programie PLC (tryby LIM / POS / CZAS / SIN, rampy, sygnały końca ruchu),
- 12 napędów, 4 joysticki ekranowe (przeciąganie gałki; pad: lewa gałka + LB = J1, prawa gałka + RB = J2),
- logowanie klawiaturą ekranową: `admin` / `admin` albo `operator` / `operator`,
- nic nie jest zapisywane – po odświeżeniu strony wszystko wraca do stanu początkowego.

Nie ma tu Asystenta AI ani funkcji systemowych pulpitu (zegar, kalibracja joysticków, programy zewnętrzne).
